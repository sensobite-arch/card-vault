# Card Vault

A personal app to scan, save and price Pokémon cards (prices in euros from Cardmarket, via [TCGdex](https://tcgdex.dev)).

- The app's code is in [`app/`](app) (React + Vite, installable as a web app).
- Every push to `main` is built and published to GitHub Pages automatically.

Run it on a PC: `cd app`, `npm install`, `npm run dev`.
